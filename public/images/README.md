# Product photos

Drop image files here, named after each item's `slug` in
`data/menuData.js` (e.g. `salankatia.jpg` for the Salankatia item,
`logo.png` for the restaurant logo).

Then set the matching `image` (or `logo`) field in
`data/menuData.js` to the file's path, e.g.:

```js
image: '/images/salankatia.jpg'
```

Until an item has an `image` set, the menu shows a dashed placeholder
box in its place — nothing breaks if photos arrive gradually.
